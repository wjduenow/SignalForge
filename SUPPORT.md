# Getting help with SignalForge

Thanks for using SignalForge! Where to go depends on what you need:

## ❓ Questions & usage help
Ask in **[GitHub Discussions → Q&A](https://github.com/wjduenow/SignalForge/discussions/categories/q-a)**.
Answered threads become a searchable FAQ, so others benefit too. Please search
existing discussions first.

## 💡 Feature requests & ideas
Open a thread in **[GitHub Discussions → Ideas](https://github.com/wjduenow/SignalForge/discussions/categories/ideas)**.
Popular ideas feed the [roadmap](https://signalforge-dbt.com/#roadmap).

## 🐛 Bugs
If something is broken or behaves incorrectly,
**[file a bug report](https://github.com/wjduenow/SignalForge/issues/new/choose)**
with the command, config, and version. Reproducible reports get fixed fastest.
Never paste warehouse rows or secrets.

## 📚 Documentation
Quick start, CLI reference, configuration, and data safety:
**<https://wjduenow.github.io/SignalForge/>**

Please don't use the issue tracker for general questions — Discussions keeps them findable.
